# 字典管理测试

使用项目 `.env` 中的本地 PostgreSQL 连接（通常为 `127.0.0.1:5433`）。测试会另建随机名称的临时数据库，结束后删除并确认不存在；不会修改 `tracebug_local` 或线上数据库。

```powershell
npm run test:dictionaries
npm run test:dictionaries:ui
```

接口测试验证历史数据迁移、字典权限与输入校验、并发冲突、新建和编辑缺陷、批量修改及停用兼容。状态测试验证延迟刷新的响应不会覆盖刚保存的字典。

字典删除沿用“编辑后保存”：已保存项须在 `deletedValues` 中明确列出，遗漏项不会被当作删除。至少保留一个启用的默认值；被缺陷当前字段或通知规则引用的值不能删除。历史活动文字和已排队消息使用快照，删除未被当前业务引用的值不会重写这些记录。

删除专项仅在显式启用的独立数据库下运行 `npm run test:dictionary-deletion`，验证三类字典删除、默认替换、引用保护、并发序列和重启不复活。

权重规则：数值越大越靠前。缺陷仍依次比较状态权重、优先级权重、更新时间倒序和编号；环境权重只控制环境选项顺序。同权重字典选项按原位置稳定展示，不能提前覆盖缺陷排序的下一层条件。

个人中心规则：仅展示状态勾选「在个人中心展示」且当前用户为负责人的缺陷；列表、侧栏数量和状态汇总使用同一条件。该开关独立于状态是否结束、是否停用，完成统计仍按「处理已结束」计算。迁移按旧排序生成权重，并将旧的非结束状态初始化为展示。

浏览器测试需要 Python 的 `playwright` 包和系统安装的 Chrome，使用独立 API `3191` / 前端 `4191` 端口；截图保存到已忽略的 `artifacts/dictionary-ui/`。仅截图保留作为测试证据，临时数据库、上传目录和进程会在测试结束时清理。

接口测试独占 `3192` 端口。运行测试前应确保这些端口没有其他开发进程占用。

## 缺陷权限专项

`npm run test:issue-permissions` 默认跳过；显式设置 `TRACEBUG_PERMISSIONS_TEST=true` 时执行。测试要求专用连接为 `127.0.0.1:5434/tracebug_local` 且没有 `DATABASE_URL` 覆盖，并另建随机临时数据库和上传目录，结束后清理。不要指向共享灰度或正式数据库。

覆盖创建人、仅负责人、无关普通成员、无关管理员的全部字段与单条/批量状态操作；只有创建人或管理员可以删除。验证普通成员混合批量的原子拒绝、拒绝删除时保留评论和附件、管理员修改后的通知事件，以及匿名/首次密码未完成会话继续被拒绝。

```powershell
$env:TRACEBUG_PERMISSIONS_TEST = 'true'
npm run test:issue-permissions
Remove-Item Env:TRACEBUG_PERMISSIONS_TEST
```
